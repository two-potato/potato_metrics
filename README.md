# Potato Metrics

Infrastructure observability experiments. Use the [isolated local demo](demo/README.md) rather than the historical root deployment configuration. The lab is intended to exercise metrics, HTTP probes, alert firing and recovery using disposable containers. No production configuration or external alerting is required.

Status: [local integration CI passed](https://github.com/two-potato/potato_metrics/actions/runs/45377212967): configuration validation, container startup, HTTP probe, alert firing and recovery. This is local lab evidence, not production certification. The historical root configuration still needs a separate security review.
